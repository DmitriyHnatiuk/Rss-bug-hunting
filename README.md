# 🐞 Bug Hunting — RS School

Учебный проект для курса RS School Fullstack Engineering (Неделя 5). Пять небольших страниц, в каждой спрятаны намеренные баги. Задача — найти и исправить их все, опираясь на описание ожидаемого поведения.

Всего **45 багов**: 2 страницы с багами вёрстки (CSS) и 3 интерактивных приложения с багами логики (JS). Сложность растёт от первого задания к последнему.

## 🚀 Как начать

1. Сделай **Fork** этого репозитория к себе на GitHub.
2. Склонируй свой форк:
   ```bash
   git clone https://github.com/<твой-логин>/<название-репозитория>.git
   ```
3. Открой проект в редакторе и запусти через Live Server (или просто открой `index.html` в браузере).
4. Создай ветку для исправлений:
   ```bash
   git checkout -b fix/bugs
   ```
5. Исправляй баги, коммить по ходу работы по [конвенции коммитов](https://rs.school/docs/git-convention).
6. Запушь ветку и открой **Pull Request** из `fix/bugs` в `main` своего форка.

> HTML-разметка на всех страницах корректна и показывает, как задание должно выглядеть и работать в исправленном виде. Меняй CSS и JS, а не структуру HTML.

## 🧰 Стек

- HTML5
- CSS3
- Чистый JavaScript (без библиотек и фреймворков)
- DevTools браузера

## 📋 Задания

### Задание 1 ⭐ — Прайс-таблица (CSS, 8 багов)

Страница с тремя тарифами (Basic / Pro / Enterprise).

| № | Что не так | Как должно быть |
|---|---|---|
| 1 | Тарифы стоят вертикально в столбик | Стоят в один ряд по горизонтали |
| 2 | Средний тариф «Pro» ничем не выделен | Выделен рамкой толщиной 2px цвета `#2563eb` |
| 3 | Список фич склеен и без маркеров | У каждой фичи вертикальные отступы 6px и зелёный маркер-галочка `✓` перед текстом |
| 4 | Кнопки «Выбрать» серые | Кнопки с синим фоном `#2563eb` |
| 5 | Цена почти не видна, сливается с фоном | Цена тёмная и контрастная, цвет `#0f172a` |
| 6 | Контент прижат к краям карточек | Внутренние отступы карточки: 32px сверху и снизу, 24px слева и справа |
| 7 | Кнопки "Выбрать" в карточках расположены на разной высоте | Кнопки "Выбрать" расположены на одной высоте у всех карточек |
| 8 | Углы острые, карточки слиплись | Углы скруглены на 12px, между карточками промежуток 24px |

### Задание 2 ⭐⭐ — Портфолио-галерея (CSS, 7 багов)

Сетка карточек проектов: картинка, название, теги, ссылка.

| № | Что не так | Как должно быть |
|---|---|---|
| 1 | Карточки идут одной колонкой | Карточки стоят в ряд, по 3 в строке |
| 2 | Карточки не переносятся при нехватке места | При нехватке места карточки переносятся на новую строку |
| 3 | Между карточками нет промежутков | Между карточками промежуток 20px |
| 4 | Галерея прижата к краю | Блок галереи центрирован по горизонтали |
| 5 | Картинки растянуты и искажены | Картинки сохраняют пропорции и обрезаются под размер блока (высота 200px), без искажения |
| 6 | При наведении карточка не реагирует | При наведении карточка плавно (за 0.2s) приподнимается на 8px, тень усиливается |
| 7 | Теги идут вертикально столбиком | Теги стоят в один горизонтальный ряд с промежутком 8px |

### Задание 3 ⭐ — Список задач To-Do (JS, 10 багов)

Добавление, отметка выполненных кликом, удаление, счётчик, фильтры.

| № | Что не так | Как должно быть |
|---|---|---|
| 1 | Кнопка «Добавить» не реагирует на клик | По одиночному клику задача добавляется в список |
| 2 | Можно добавить пустую строку или пробелы | Пустая строка (в том числе из одних пробелов) не добавляется; показывается сообщение «Введите текст задачи» |
| 3 | После первой задачи список ломается | Можно добавлять любое количество задач подряд, список продолжает работать |
| 4 | Клик по задаче не отмечает её выполненной | Одиночный клик по тексту задачи зачёркивает её |
| 5 | Повторный клик не снимает отметку | Повторный клик убирает зачёркивание |
| 6 | Кнопка удаления не удаляет задачу | Клик по кнопке «✕» убирает задачу из списка и из счётчика |
| 7 | Счётчик показывает неверное число | Счётчик показывает количество невыполненных задач |
| 8 | Фильтры «Активные / Выполненные» не фильтруют | «Активные» показывают только невыполненные, «Выполненные» — только выполненные, «Все» — все задачи |
| 9 | При действиях список задач дублируется | На странице ровно столько задач, сколько добавлено, без повторов |
| 10 | «Очистить выполненные» стирает все задачи | Удаляются только выполненные задачи, активные остаются |

### Задание 4 ⭐⭐ — Корзина (JS, 10 багов)

Список товаров, корзина с количеством, промокодом и итогом. Промокод для скидки — `SALE10`.

| № | Что не так | Как должно быть |
|---|---|---|
| 1 | Кнопка «В корзину» не добавляет товар | Клик по «В корзину» добавляет товар в корзину |
| 2 | Повторное добавление создаёт дубль-строку | Повторное добавление того же товара увеличивает его количество, а не создаёт вторую строку |
| 3 | Кнопка «+» не увеличивает количество | Кнопка «+» увеличивает количество товара на 1 |
| 4 | Кнопка «−» уходит в ноль и минус | Кнопка «−» уменьшает количество на 1, но не ниже 1 |
| 5 | Сумма строки не пересчитывается | Сумма строки равна цене товара, умноженной на его количество |
| 6 | Итоговая сумма считается неверно | Итог равен сумме всех строк корзины |
| 7 | Счётчик-бейдж показывает число строк | Бейдж показывает суммарное количество товаров (сумму количеств во всех строках) |
| 8 | Промокод не даёт скидку либо действует всегда | Промокод `SALE10` даёт скидку 10% на итог; при других или пустом коде скидки нет |
| 9 | «Очистить корзину» очищает не полностью | «Очистить корзину» удаляет из корзины все товары |
| 10 | У пустой корзины нет сообщения, итог некорректен | При пустой корзине показывается «Корзина пуста», итог равен 0 |

### Задание 5 ⭐⭐⭐ — Каталог с фильтрами (JS, 10 багов)

Каталог с поиском, фильтром по категории и сортировкой по цене.

| № | Что не так | Как должно быть |
|---|---|---|
| 1 | Каталог пуст при любых фильтрах | По умолчанию, без выбранных фильтров, показаны все товары |
| 2 | Старые карточки остаются после смены фильтра | После смены фильтра на странице только подходящие карточки, старые не остаются |
| 3 | Поиск чувствителен к регистру | Поиск не зависит от регистра букв (iphone, IPHONE, iPhone дают одинаковый результат) |
| 4 | Поиск находит только по полному совпадению | Поиск находит товар по части названия |
| 5 | Фильтр категории показывает не ту категорию | Фильтр показывает только товары выбранной категории; «Все категории» — все товары |
| 6 | Сортировка по цене перепутана | «Цена ↑» сортирует по возрастанию цены, «Цена ↓» — по убыванию |
| 7 | «По умолчанию» не возвращает исходный порядок | «По умолчанию» показывает товары в исходном порядке, как при загрузке страницы |
| 8 | Фильтры не работают вместе | Поиск, категория и сортировка действуют одновременно (комбинируются) |
| 9 | «Найдено: N» всегда показывает общее число | «Найдено: N» показывает количество товаров после фильтрации |
| 10 | «Сбросить фильтры» не сбрасывает | «Сбросить фильтры» очищает поиск, сбрасывает категорию и сортировку и показывает все товары |
